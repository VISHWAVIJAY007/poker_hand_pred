# Poker Hand Prediction

A machine learning project for predicting poker hand classifications using data analysis and predictive modeling techniques.

## 📋 Project Overview

This project applies data science and machine learning methods to classify poker hands. The model analyzes card features and predicts hand rankings (e.g., high card, pair, two pair, three of a kind, straight, flush, full house, four of a kind, straight flush).

## 🎯 Objectives

- Explore and understand poker hand datasets
- Perform exploratory data analysis (EDA)
- Develop and train classification models
- Evaluate model performance and accuracy
- Generate insights about hand distributions and patterns

## 📊 Dataset

The project uses poker hand data with features representing:
- Card suits and ranks
- Hand characteristics
- Classification labels

## 🛠️ Technologies & Libraries

- **Python 3.x**
- **Jupyter Notebook** - Interactive analysis and modeling
- **Pandas** - Data manipulation and analysis
- **NumPy** - Numerical computations
- **Scikit-learn** - Machine learning algorithms
- **Matplotlib / Seaborn** - Data visualization

## 🚀 Getting Started

### Prerequisites

Ensure you have Python 3.x installed with the following packages:
```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
```

### Installation

1. Clone the repository:
```bash
git clone https://github.com/VISHWAVIJAY007/poker_hand_pred.git
cd poker_hand_pred
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```
